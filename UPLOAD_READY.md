## Upload Instructions

### Step 1: Create ZIP File
1. Navigate to `shopify-theme-pachamana` folder
2. Select ALL files and folders (including hidden files if visible)
3. Right-click → "Send to" → "Compressed (zipped) folder"
4. Name it `pachamana-theme.zip`

### Step 2: Upload to Shopify
1. Go to Shopify Admin
2. Navigate to: **Online Store** → **Themes**
3. Click **"Add theme"** button
4. Select **"Upload zip file"**
5. Choose your `pachamana-theme.zip` file
6. Wait for upload and validation

### Step 3: Verify Upload
- ✅ No validation errors should appear
- ✅ Theme should appear in your theme library
- ✅ You can preview the theme
- ✅ You can publish when ready
